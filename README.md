# aikatan

aikatan is the official cultural fest website of **Ramkrishna Mahato Government Engineering College**. This platform showcases the latest events, competitions, workshops, and cultural programs organized as part of the fest.

## 📌 Features
- Interactive landing page with event details
- Dynamic schedule of competitions and workshops
- Dedicated timeline for cultural fest performances
- Online registration for events
- Responsive design for seamless access across devices
- Smooth animations and user-friendly interface

## 🎭 Cultural Fest 2026 Highlights

The Cultural Fest segment celebrates regional pride, music, live performances, and campus community participation across two evenings in **May 2026**.

### Day 1 - 15 May 2026
- **18:00** - Inauguration Ceremony
- **19:00** - Chhou Nach *(special pride of Purulia)*
- **19:30** - College Cultural Programme
- **21:00** - Tech Fest Prize Distribution
- **21:30 - 22:00** - Break
- **22:30** - The Paper Planes
- **01:00** - Ananya Chakraborty Live

### Day 2 - 16 May 2026
- **18:00** - College Cultural Programme
- **19:30** - Reunion
- **20:30 - 21:30** - College Cultural Programme
- **21:30 - 22:00** - Break
- **23:00** - Fakira Live Concert
- **01:30** - DJ Night

### What Visitors Can Expect
- Live stage performances and concerts
- Regional cultural showcase and student acts
- Evening-friendly event flow with scheduled breaks
- A mix of tradition, campus spirit, and entertainment

## 🛠️ Tech Stack
- **Frontend:** Next.js, Tailwind CSS, Framer Motion
- **Deployment:** Vercel

## 🔧 Installation & Setup

To run the project locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/rkmgec-admin/aikatan-rkmgec.git
   cd aikatan-rkmgec
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```
   The site will be available at `http://localhost:3000`
